1.4  Conclusión sobre la estructura
--------------------------------------------------------------------------------

Hay DOS formas de item en el array `setup`, según el tipo de fase:

  A) Items de fase regular (Fase 1 / Fase 2 / Fase Final):
     - stage      : nombre de la fase
     - name       : tipo de componente -> "Zona" | "Examen" | "NSP" | "SDE"
     - phase_uuid : UUID común a todos los items de la misma fase
     - solo UNO de:
         · score (string|number) cuando name = "Zona" | "Examen"
         · nsp   (boolean)       cuando name = "NSP"
         · sde   (boolean)       cuando name = "SDE"

  B) Items de recuperación (Recuperacion1 / Recuperacion2):
     - stage = name = "Recuperacion1" o "Recuperacion2" (mismo string en ambos)
     - NO tiene phase_uuid
     - weighting (string, ej. "40")
     - score (cuando hubo nota) o nsp (cuando no se presentó)

⚠ No existen fases "Extraordinario1" / "Extraordinario2" en modul_dev.
   (Si necesitás verificar en producción, usar el mismo query 1.1)

2.1  Query principal
--------------------------------------------------------------------------------

  SELECT
    sc.score_id,
    st.student_id,
    st.student_id_card                              AS carne,
    st.name                                         AS alumno,
    sec.section_id,
    c.course_id,
    JSON_UNQUOTE(JSON_EXTRACT(c.setup, '$.code'))   AS curso_code,
    c.name                                          AS curso_nombre,
    sn.season_id,
    sn.name                                         AS periodo,
    sc.setup                                        AS score_setup
  FROM crs_score sc
  INNER JOIN std_student              st  ON st.student_id  = sc.student_id
  INNER JOIN crs_assignation_section  sec ON sec.section_id = sc.section_id
  INNER JOIN crs_course               c   ON c.course_id    = sec.course_id
  INNER JOIN crs_assignation_season   sn  ON sn.season_id   = sec.season_id
  WHERE st.student_id_card = '2504206'
    AND (sn.name = '2502' OR sn.name = '2025-02' OR sn.name LIKE '%2502%')
    AND c.name LIKE '%Contabilidad I%'
